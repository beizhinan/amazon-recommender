# 亚马逊商品推荐系统项目报告

> 跨媒体推荐系统前沿 · Books 5-core 数据集 · 评分预测 + Top-N 推荐

## 摘要

本项目在 Amazon Books 5-core 数据集（889 万评分、60.4 万用户、36.8 万商品）上完成两项推荐任务：

- **评分预测**：最终算法 **TAB-H**（门控分段加权融合，bias + ItemCF + SVD + FAR）达到 **RMSE 0.8939 / MAE 0.6496**，相对最优单模型双偏置基线（0.9023 / 0.6574）提升 0.93% / 1.19%，且权重高度可解释。
- **Top-N 推荐**：最终算法 **Hybrid_global**（BPR + 非对称余弦 ItemKNN 二路融合）达到 **NDCG@10 0.0746 / Recall@10 0.1024 / HitRate@10 18.30%**，相对 MostPop 提升 1,391%（NDCG）/ 1,054%（Recall）。

两条任务最终都指向同一个核心结论：**在这类「用户多、每人极少、评分偏正、商品长尾」的极端稀疏数据上，性能提升来自信号的正交性与稳健收缩，而非模型容量。** 这一结论由多个受控负结果反复验证（时序偏置、序数校准、分段 λ、元数据共购图）。

---

## 1. 项目背景与目标

推荐系统面临两类经典任务：

1. **评分预测**：给定用户历史评分，预测其对未评分商品的评分值（回归问题）。
2. **Top-N 推荐**：为每个用户生成一个长度为 N 的商品排序列表（排序问题）。

项目选用 Amazon 商品评论数据集（McAuley 等人）中的 **Books** 类目，5-core 版本（每个用户与每件商品至少 5 条交互），这是推荐系统研究中最常用的公开基准之一。

**核心挑战**来自数据本身的三重特性，它们贯穿全文、决定了每一步的方法选择：

| 特性 | 数值 | 直接后果 |
|------|------|----------|
| 极端稀疏 | 稀疏度 99.9968% | 邻居证据不足，协同信号噪声大 |
| 评分偏正 | 5 星占 56%，≥4 星占 81% | 「预测偏向高分」本身就能降 RMSE |
| 商品长尾 | 36.8 万商品，平均每件仅 24 条评分 | 商品偏置/隐表示估计噪声极大 |

## 2. 数据与预处理

### 2.1 数据集

- 来源：Stanford SNAP 镜像 `reviews_Books_5.json.gz`
- 规模：8,898,041 条评分 / 603,668 用户 / 367,982 商品

### 2.2 预处理规则

1. **字段保留**：`reviewText`、`summary`、`unixReviewTime`、`helpful`、`reviewerName` 等全部保留，`helpful` 拆为 `helpful_no` / `helpful_yes`。
2. **清洗**：丢弃缺失 user/item/rating 的记录，过滤评分不在 1–5 的记录；剔除文本中的 NUL 字符与孤立代理字符（否则 CSV 写出报错）。
3. **去重**：同一 `(user_id, item_id)` 保留时间戳最新的一条，避免训练/测试泄漏。
4. **划分**：每个用户随机 20% 评分作测试集，其余作训练集（随机种子 42）。

### 2.3 划分后统计

| 项目 | 训练集 | 测试集 |
|------|--------|--------|
| 评分数 | 7,142,099 | 1,755,942 |
| 商品数 | 367,965 | 318,935 |
| 稀疏度 | 99.9968% | 99.9991% |
| 每用户评分中位数 | 6 | 2 |

评分分布极度偏正（5 星 56.0%、≥4 星 81.0%、1–2 星仅 8.3%），这是理解后文所有现象的前提。

## 3. 评估协议

### 3.1 评分预测

- **指标**：`MAE = mean|r̂ − r|`、`RMSE = sqrt(mean(r̂ − r)²)`，预测裁剪到 `[1, 5]`。
- 邻域模型无可用邻居时回退到双偏置基线，单独统计回退率。

### 3.2 Top-N 推荐

- **候选集**：全部 367,982 商品（全量排序，非采样负例），排除用户在训练集已交互的商品。
- **评估**：随机 10,000 用户，K=10。
- **指标**：Precision@10 / Recall@10 / F1@10 / NDCG@10 / HitRate@10 + 覆盖率（逐用户宏平均）。

> 全量排序协议下，从 36.8 万候选里只取 top-10，随机基线的 Recall 仅 0.0027%。因此绝对指标量级天然很低，评判应以「相对基线的倍数」与「相对上一版本的增幅」为准，而非绝对数值。

## 4. 任务一：评分预测

### 4.1 基线系统

实现 8 类模型共 31 组配置：GlobalMean、UserMean、BiasBaseline、ItemCF、UserCF、Slope One、SVD、NeuMF。关键结果（按 RMSE 升序）：

| 模型 | 配置 | MAE | RMSE | 回退率 |
|------|------|-----|------|--------|
| **bias** | reg=3 | **0.6574** | **0.9023** | 0 |
| svd | 50×30 | 0.6672 | 0.9063 | 0 |
| ncf | 64/64 [128,64,32] | 0.6605 | 0.9089 | 0 |
| itemcf | k=50 shrink=25 | **0.6531** | 0.9265 | 63.44% |
| usercf | k=20 shrink=25 | 0.6688 | 0.9226 | 80.82% |
| slopeone | k=100 min=2 | 0.6687 | 0.9603 | 45.73% |
| usermean | reg=10 | 0.7290 | 0.9580 | 0 |
| global | — | 0.8387 | 1.0562 | 0 |

**关键观察**：

1. **双偏置（reg=3）是单模型上限**：RMSE 最优且只需 3 秒，比 SVD 低 0.44%、比 NCF 低 0.68%。
2. **ItemCF 的 MAE 最低（0.6531）但 RMSE 明显劣于 bias（0.9265）**：协同修正幅度大，猜中时很准、猜偏时误差被平方放大——这为融合提供了明确动机（MAE 与 RMSE 的两类误差结构互补）。
3. **邻域模型回退率极高**（ItemCF 63.4%、UserCF 80.8%）：共现信息严重不足，大部分预测是基线在兜底。

### 4.2 为什么单模型难以突破 0.90

- **用户效应主导**：UserMean 已达 0.9580，商品偏置 `b_i` 因平均每件仅 24 条评分而噪声极大。
- **极端稀疏 + 长尾**：每用户中位数仅 6 条评分，CF 的邻居证据不足。
- **评分偏斜**：模型的期望输出天然靠近 4.2–4.3，「稳定收缩」比「激进协同修正」更能降平方误差。

**结论**：继续堆叠单一模型（更深 MF、更大 K、更多隐因子）收益趋零，需要**误差结构互补的正交信号**。

### 4.3 文献调研 → 方向决策

| 方向 | 代表工作 | 结论 | 决策 |
|------|----------|------|------|
| 评论文本建模 | DeepCoNN / NARRE / MPCNN | 增益 0–1.3%，且 DeepCoNN 用被测评论本身输入，属 transductive 泄漏 | 不采用 |
| 时序动态偏置 | Koren (KDD'09) | 5-core 每用户评分过稀，漂移无法稳定估计 | 已消融，负结果 |
| 序数/分位数回归 | RecRec 等 | 主要改善 MAE 与排序一致性，对 RMSE 无稳定增益 | 不采用 |
| 特征增强 + GBDT | target encoding / GBDT | 需足够样本才能超过线性偏置 | 采用（FAR） |
| 模型融合/stacking | 门控加权、分段 | 异质模型间稳定有效，性价比最高 | **采用（TAB-H）** |

调研核心判断：**提升来自信号正交性而非模型容量**。

### 4.4 尝试与最终算法

**尝试一：时序动态偏置（TAB）— 负结果**

```
r̂ = μ + b_u + α_u·dev_u(t) + b_i + b_{i,Bin(t)} + g_{Bin(t)}
```

在 3,000 用户子集逐项消融：MAE 有 0.5%–0.8% 边际改善，但 **RMSE 全部持平或变差**。漂移项在每用户 6 条评分时无法稳定估计，反而引入方差。不进入最终模型。

**尝试二：FAR 特征增强残差模型 — 正向但依赖样本量**

把「双偏置无法表达的异方差」交给 GBDT：10 维特征（用户/商品均值与离散度、`log1p(评分数)`、时间特征），特征统计一律**留一法**防泄漏。结果：

| 模型 | val RMSE | test RMSE | test MAE |
|------|----------|-----------|----------|
| bias（同子集） | 0.9111 | 0.9059 | 0.6608 |
| FAR-g1（600 树） | 0.9076 | **0.9028** | **0.6588** |

关键现象：小样本（3 千用户）上 FAR 反而差 5.5%，全量上才赢 0.34%——**树模型需要足够样本才能估准非线性收缩**。FAR 单独收益小，但它的优势样本（低频/冷门）与 CF 的覆盖样本几乎不重叠，正是融合的价值来源。

**尝试三：TAB-H 门控分段加权融合 — 最终算法**

```
r̂ = clip( w₀ + w₁·r̂_bias + w₂·r̂_cf + w₃·r̂_svd + w₄·r̂_far , 1, 5 )
```

三个设计要点：

1. **门控**：`cf` 只在存在可用协同邻居时进入组合，避免把基线回退值当独立信号。
2. **分段**：门控内按用户训练评分数分桶（[0,5]/(5,15]/(15,50]/>50），每段独立求解权重。
3. **非负最小二乘（NNLS）**：`w ≥ 0` 避免负权重放大噪声，段内样本 <2000 时回退全局权重。

| 模型 | test RMSE | test MAE |
|------|-----------|----------|
| bias（同子集） | 0.9059 | 0.6608 |
| ItemCF（覆盖 33.15%） | 0.8200 | 0.5149 |
| SVD | 0.9100 | 0.6711 |
| FAR-g1 | 0.9028 | 0.6588 |
| **TAB-H 四路（+ FAR）** | **0.8939** | **0.6496** |

相对全量训练的 bias 最优：**RMSE −0.93%、MAE −1.19%**（两项同时改善，非指标互换）。学到的分段权重高度可解释：**用户越活跃越信偏置，越冷门越信 FAR 收缩**；SVD 权重几乎全为 0（与 bias/FAR 高度冗余）。

## 5. 任务二：Top-N 推荐

### 5.1 模型

| 模型 | 核心做法 |
|------|----------|
| MostPop | 按训练流行度排序（基线） |
| RatingPred | `μ + b_u + b_i` 打分（评分预测迁移） |
| ItemKNN | 非对称余弦相似度 + top-K 邻居 |
| BPR | 成对排序损失矩阵分解（64 维隐因子） |
| Hybrid | BPR + ItemKNN 加权融合 |

**非对称余弦**（Steck 2019）是 ItemKNN 的核心：`s_ij = C_ij / (‖w_i‖^α · ‖w_j‖^(1-α))`。α=0.5 为对称余弦；α>0.5 压制热门商品的相似度，用于对抗 Books 上严重的流行度偏置。

### 5.2 调参与三轮迭代

| 版本 | 关键改动 | ItemKNN NDCG | Hybrid NDCG |
|------|---------|--------------|-------------|
| v1 | 对称余弦，k=200，无衰减 | 0.0227 | 0.0288 |
| v2 | 非对称余弦 α=0.7，2 年衰减 | 0.0472（+108%） | 0.0581（+102%） |
| v3 | α=0.85，k=800，BM25 归一化，去衰减 | **0.0707（+50%）** | **0.0746（+28%）** |

三个最有效的改动：

1. **非对称余弦 α 0.5→0.85**（最大增益）：压制流行度偏置。
2. **BM25 用户活跃度归一化**（+33%）：`w_ui /= log2(1+n_u)`，修正重度用户对共现统计的支配。
3. 两个「看似有用」的改动被判负：**时间衰减**（符号随配置翻转）、**分段 λ**（val +2.9% 但 test −0.5%，过拟合）。

### 5.3 全量测试结果

| 模型 | P@10 | R@10 | F1@10 | NDCG@10 | HitRate | 覆盖率 |
|------|------|------|-------|---------|---------|--------|
| **Hybrid_global** | **0.0231** | **0.1024** | **0.0328** | **0.0746** | **0.1830** | 16.23% |
| ItemKNN（α0.85, k800, BM25） | 0.0221 | 0.0956 | 0.0309 | 0.0707 | 0.1714 | 19.08% |
| BPR | 0.0063 | 0.0274 | 0.0088 | 0.0170 | 0.0553 | 2.24% |
| MostPop | 0.0016 | 0.0089 | 0.0025 | 0.0050 | 0.0160 | 0% |
| RatingPred | 0.0000 | 0.0000 | 0.0000 | 0.0000 | 0.0000 | 0% |

- Hybrid 相对 MostPop：**NDCG +1,391%，Recall +1,054%**；相对随机基线为 **3,500 倍以上**。
- **RatingPred 全为 0**：`μ + b_u + b_i` 中 `b_u` 是每用户常数，不改变商品间排序，所有用户得到同一个「全局 b_i 最高」列表。这直接证明 **评分预测精度高 ≠ 排序能力强**，排序必须建模相对偏好或邻域协同。
- **BPR 始终很弱**（NDCG 仅为 ItemKNN 的 24%）：99.9968% 稀疏度下隐因子学不到长尾商品的有效表示。

### 5.4 尝试：元数据共购图（负结果）

**动机**：ItemKNN 的共现信号只覆盖 19% 商品，剩余 81% 无邻居证据。Amazon 元数据中的 `also_bought` / `also_viewed` 提供独立商品关联图，理论上能补足覆盖。

**实现**：下载并解析 `meta_Books.json.gz`（826 MB），构建加权对称共购图 `A = 1.0·buy + 0.5·view`（nnz 17,535,362），**覆盖 90.5% 商品**。新增 `MetaItemKNN`（在共购图上跑非对称余弦）与三路融合 `TripleHybrid = BPR + lam1·ItemKNN + lam2·MetaItemKNN`。

| 模型 | NDCG@10 | R@10 | 覆盖率 |
|------|---------|------|--------|
| ItemKNN（评分共现，对照） | 0.0707 | 0.0956 | 19.08% |
| MetaItemKNN（元数据共购） | 0.0414 | 0.0633 | 17.34% |
| Hybrid_global（二路，最优） | **0.0746** | 0.1024 | 16.23% |
| TripleHybrid（三路融合） | 0.0639 | 0.0968 | 16.79% |

**结论：负结果**。MetaItemKNN 比 ItemKNN 低 41%，三路融合比二路低 14%，覆盖率不升反降。三条根因：

1. **also_bought 不是正交信号**：与评分共现捕获同一件事（商品被共同消费），区别仅在共购是跨用户全局的、无个性化，质量更低。
2. **α=0.85 惩罚在源侧**：候选侧只开 0.15 次方，热门畅销书依然霸榜，覆盖率起不来。
3. **lam2 单调递减**（0.25/0.5/1.0 → val NDCG 0.0562/0.0497/0.0444），最优卡在下界，说明 MetaItemKNN 最优权重趋近 0。

这个负结果从反面再次印证了全文主线：**正交的个性化信号才有融合价值，全局冗余信号只会稀释强信号。**

## 6. 结论与展望

### 6.1 结论

1. **评分预测**：双偏置是单模型上限，TAB-H 通过「门控 + 分段 + 非负最小二乘」融合 bias/CF/SVD/FAR 四路正交信号，达到 RMSE 0.8939，且权重可解释。
2. **Top-N**：非对称余弦（压制流行度偏置）+ BM25（修正活跃度支配）是两大有效改动，Hybrid_global 达到 NDCG 0.0746。
3. **贯穿全文的方法论**：在极端稀疏 + 偏正 + 长尾的数据上，**性能来自信号正交性与稳健收缩，而非模型容量**。这一判断由多个受控负结果验证：时序偏置、序数校准、分段 λ、元数据共购图。

### 6.2 展望

- 当前瓶颈在覆盖率：共现信号只覆盖 19% 商品，元数据共购图已证明不是有效补充，真正的正交信号仍需探索（如类目层级、跨域信号）。
- 若需更细粒度的模型对比，可改用采样负例评测协议，让绝对指标更敏感、更可解释。
- 更深的图模型（LightGCN、EASE）可能强于 ItemKNN，但需在可控负载下评估其与稀疏度的适配性。
